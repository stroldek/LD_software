# Lead Database Manager / ZAMOVO — v1.5.0

**Тестовая сборка:** мониторинг выбранных Telegram-диалогов личного аккаунта, фильтры по словам и фразам, шаблоны, лид-база, Excel и статистика запусков.

## Новое в 1.5.0

- Сохранение шаблонов фильтров: слова, фразы, режим совпадения, интервал и настройка «любое сообщение».
- Отдельные поля фильтра: ключевые слова, ключевые фразы/словосочетания; режимы «Слова», «Фразы», «Оба».
- В лидах хранится и выгружается дата сообщения, отдельно от даты добавления в базу.
- Очистка базы требует повторно ввести пароль панели (`ADMIN_TOKEN`), не только нажать подтверждение.
- Минималистичный обзор: текущий запуск (длительность, циклы, чаты, сообщения), лиды за сегодня/7/30 дней, конверсия запуска, измеряемая активность и ориентиры бесплатных лимитов.
- «План» вместо «Первой проверки»: цель по лидам, опциональный шаблон и источник; при закрытии — запись в журнал и одно уведомление подключённого Telegram-аккаунта на указанный контакт `@username`.
- Журнал вынесен в отдельную вкладку.
- В интерфейс добавлен логотип ZAMOVO/LEAD с прозрачным фоном.
- Подбор «Потенциальных источников» ищет по доступным диалогам аккаунта и поддерживает массовое добавление выбранных источников в мониторинг.

## Ограничения

- «Потенциальные источники» — локальный поиск по диалогам подключённого аккаунта. Telegram не предоставляет в этом приложении полноценный глобальный поиск тематических групп/чатов. Вход/подписка в найденные сообщества автоматически не выполняются; выбирайте и добавляйте доступные источники вручную.
- Мониторинг — только чтение выбранных источников. Единственная отправка сообщения — уведомление владельцу о достижении цели, если он указал контакт.
- Счётчики D1/Workers в обзоре показывают измеряемую активность мониторинга. Точные `rows_read`, `rows_written`, CPU и billing-запросы смотрите в Cloudflare Analytics.
- Сегменты, полноценный CRUD лидов, импорт и другие функции относятся к следующим этапам.

## Telegram и API credentials

API ID / API Hash — идентификаторы приложения Telegram, а не личного аккаунта. Одни ключи можно использовать для подключения разных личных аккаунтов через QR или номер телефона. Сессия подключённого аккаунта хранится отдельно и зашифрована.

## Обновление существующей базы

В 1.5.0 добавлена миграция `migrations/0004_dashboard_templates_phrases.sql`. Если в D1 уже применены 0001, 0002 и 0003, выполнить только 0004 — ровно один раз. Миграция добавляет фильтр-фразы, шаблоны, статистику запусков и цели, не удаляя лиды и Telegram-сессию.

## Развёртывание

1. Cloudflare Worker, D1 binding `DB`, Durable Object binding `TG`.
2. Secrets `ADMIN_TOKEN` (20+ символов) и `APP_SECRET` (24+ символов).
3. В D1 → SQL Console выполнить миграции 0001–0004 по порядку для новой базы; на существующей базе версии 0.1.4 выполнить только 0004.
4. После публикации открыть панель, запустить диагностику Telegram, проверить QR-вход.
5. `@username` для уведомления о плане задаётся на странице «Аккаунт Telegram»; поле проверяет формат username.

## Cloudflare Free — ориентиры

На Workers Free: 100 000 запросов/день, 10 ms CPU на запрос. На D1 Free: 5 млн прочитанных строк/день, 100 000 записанных строк/день, 500 MB на базу (до 10 баз). В приложении каждое совпавшее сообщение примерно приводит к 3 строковым записям D1 (hit, lead insert/update, обновление поискового поля); теоретический потолок по записи — около 33 тыс. совпадений/день до накладных расходов. Реальный потолок ниже из-за мониторинга, индексов, логов и повторных совпадений.

Cloudflare может изменять тарифы. Официальные страницы: [Workers limits](https://developers.cloudflare.com/workers/platform/limits/), [D1 limits](https://developers.cloudflare.com/d1/platform/limits/), [D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/).
