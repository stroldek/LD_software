ШАГ 1

Ключи приложения Telegram

—

API ID и API Hash идентифицируют приложение ZAMOVO, а не Telegram-аккаунт. Один набор ключей можно использовать для входа в разные личные аккаунты: откройте my.telegram.org → войдите по номеру → API development tools → создайте приложение (название любое) → скопируйте api_id и api_hash.

Ключи приложения хранятся на сервере в зашифрованном виде и никогда не возвращаются в браузер. Они не привязаны к аккаунту, который вы подключаете ниже.

API-ключи не привязаны к подключённому аккаунту. Авторизация и сохранённая сессия относятся только к аккаунту во втором блоке.

ШАГ 2

Подключение аккаунта

—
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

Диагностика соединения

Проверяет по очереди: настройки сервера, базу, загрузку библиотеки Telegram, сетевое соединение и шифрованное рукопожатие. Каждый шаг показывает, где именно остановка.

    i

    Подключённый аккаунт — это обычный вход «как с ещё одного устройства». Для тестов лучше использовать отдельный или запасной аккаунт: Telegram может ограничить аккаунт, если он ведёт себя как робот (частые запросы, массовые действия). Текущая версия только читает выбранные чаты и ничего не пишет и не меняет в аккаунте.

    ШАГ 3

    Что искать

    Поиск без учёта регистра и «ё/е». Слова и фразы вводятся отдельно; длинная фраза снижает шум.
    ШАГ 4

    Запуск

    Проверить прямо сейчас

    Читает последние сообщения выбранных чатов и сразу применяет условия — удобно, чтобы убедиться, что всё работает, не дожидаясь новых сообщений.
